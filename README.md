# Архив Telegram — college_mdk01_bot

## GitHub Pages

Просмотр архива: https://sergannn.github.io/college-mdk01-bot/

Страница содержит поиск по сообщениям и авторам, фильтры по группе и датам,
статистику и выгрузку текущей выборки в CSV. Время отображается по Москве.
Группа 1092 до и после преобразования в супергруппу показывается вместе.
В архиве шесть групп: 1092, 1094, «МДК 01.01», «РМП 23/1093»,
«Информационная безопасность группа 3112» и «26290911/3111 Инфбез».
Фотографии и изображения, отправленные файлами, отображаются в сообщениях и открываются
в полном размере. Статичные стикеры видны как картинки; WebM-стикеры воспроизводятся,
а оригиналы анимированных TGS-стикеров доступны для скачивания.

GitHub Pages общедоступен, но переписка публикуется только в зашифрованном виде:
AES-256-GCM, ключ из пароля через PBKDF2-SHA256 (310 000 итераций), случайные salt и IV.
Пароль не хранится на GitHub и не отправляется из браузера. Локально он лежит
в `data/pages-password.txt` (права 600). Передавайте пароль только тем, кому
нужен доступ к переписке. Получатель пароля сможет прочитать и скачать снимок.

`build_snapshot.py` читает SQLite в согласованной транзакции, отправляет снимок
Node.js через stdin и пишет только шифротекст в `docs/archive.enc.json`.
Фотографии из `message_media` шифруются тем же ключом с отдельным случайным IV
для каждого файла и публикуются в `docs/media/`. Браузер расшифровывает их по мере
прокрутки. При закрытии архива ключ и ссылки на расшифрованные картинки удаляются
из состояния страницы. Текст и фотографии доступны только после ввода пароля.
Токен бота, SQLite, JSON-экспорты и пароль исключены из Git. Страница не
запрашивает сторонние ресурсы и не интерпретирует текст сообщений как HTML.

Страница показывает снимок, а не подключение к живой базе. Чтобы обновить вручную:

```sh
bash /Users/servas/college_mdk01_bot/publish_snapshot.sh
```

Для сборки снимка нужны Python 3 и Node.js; бот по-прежнему использует только Python.
При смене пароля создавайте новый снимок. Ранее опубликованные снимки могут
оставаться в истории Git и читаются прежним паролем; смена пароля не отзывает
уже скачанные копии.

Отдельный локальный проект для Mac mini. Python 3, стандартная библиотека, SQLite.
Бот принимает сообщения групп, супергрупп и каналов через long polling.
Личные сообщения в архив не записываются. Бот ничего не отправляет в чаты.

## Файлы

- `bot.py` — приём и сохранение.
- `config.json` — секретный токен; права 600, исключён из Git.
- `data/messages.sqlite3` — база данных; не размещать в публичном каталоге сайта.
- `data/receiver.log`, `data/receiver.error.log` — журналы без текста сообщений и токена.
- `media_store.py` — перенос фотографий из экспорта в приватное хранилище.
- `data/media/` — оригиналы фотографий, имена по SHA-256, исключены из Git.

В `messages` находится актуальная версия сообщения, в `updates` — исходные
обновления и история полученных правок. Уникальный ключ сообщения — chat_id + message_id.
При получении через Bot API вложения сохраняются как метаданные и Telegram file_id
в JSON payload; бот пока не скачивает новые файлы автоматически. Фотографии
истории загружаются через Telegram Desktop и импортируются отдельно.
Удаления обычных сообщений Telegram боту не сообщает.
Повторная доставка не создаёт дублей; offset сохраняется в одной транзакции с сообщениями.

## Запуск и обслуживание

Автозапуск: `~/Library/LaunchAgents/ru.panfilius.college-mdk01-bot.plist`.
Он работает в пользовательской сессии после входа в macOS. Компьютер должен
быть включён, не спать и иметь интернет. Очередь Telegram хранится не более 24 часов.

Проверка:

```sh
launchctl print gui/$(id -u)/ru.panfilius.college-mdk01-bot
sqlite3 /Users/servas/college_mdk01_bot/data/messages.sqlite3 'SELECT count(*) FROM messages;'
```

После замены токена в `config.json`:

```sh
launchctl kickstart -k gui/$(id -u)/ru.panfilius.college-mdk01-bot
```

Для всех сообщений группы назначьте бота администратором или отключите
Privacy Mode в BotFather и добавьте бота в группу заново.
Старая история чатов через Bot API не загружается.

## Импорт старой истории

В Telegram Desktop откройте нужную группу → меню → «Экспорт истории чата».
Выберите JSON, полный диапазон дат, «Photos», «Stickers» и максимальный лимит размера файла.
Для изображений, отправленных документами, включите также «Files».
Импортёр принимает `result.json` одной группы, а не экспорт всего аккаунта.

Пример предварительной проверки (укажите точный ID группы):

```sh
cd /Users/servas/college_mdk01_bot
/opt/homebrew/bin/python3 import_history.py /path/to/result.json --chat-id=-5282682239
```

Для записи добавьте `--apply`. Перед записью создаётся SQLite backup в `data/`.
Импорт проверяет ID чата, сохраняет исходные данные в `imported_messages`,
добавляет только отсутствующие сообщения и не меняет polling offset.
Сообщения, уже полученные ботом, имеют приоритет. Повторный импорт не создаёт
дубликатов. В обычных группах номера сообщений зависят от аккаунта: импорт
использует отрицательные ID и сопоставляет пересечения по автору, времени и тексту,
только когда совпадение однозначно. Исходные номера остаются в JSON.
Если экспорт супергруппы содержит историю до преобразования, импорт находит
старый chat_id по событию миграции, уже полученному ботом. Старый и новый чаты
не объединяются, поскольку номера сообщений в них могут пересекаться.
Если бот никогда не видел старую группу, отрицательные номера старой истории
сохраняются в текущей супергруппе; положительные номера Bot API с ними не пересекаются.
Номера ответов в исходном JSON относятся к экспорту, а не к Bot API.
Фотографии, изображения-документы и стикеры из папки рядом с `result.json` копируются
в `data/media/`, а связи
с сообщениями сохраняются в `message_media`. Импорт проверяет, что путь не выходит
за каталог экспорта, проверяет тип изображения и сообщает число недоступных фото.
Видео, аудио и прочие вложения, кроме стикеров, пока остаются метаданными. JSON payload имеет
`source=telegram_desktop_export` и исходное сообщение в `message`.

Резервная копия работающей базы:

```sh
sqlite3 /Users/servas/college_mdk01_bot/data/messages.sqlite3 '.backup /Users/servas/college_mdk01_bot/data/messages-backup.sqlite3'
```
